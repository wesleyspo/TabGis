Modelo de dados — GIS / OMS / MWM

Partição de schemas: gis (consumidores + equipamentos), oms (chamadas, ordens, tarefas, eventos de rede, interrupções), mwm (equipas, turnos, atribuições, rotas). Ver Database_Structure_Context.md. Utilizadores: security.users; ordens canónicas: owner_id, locked_by_id. POC: operations.* + API.
